# SEO Performance Dashboard (Power BI)

> **Note:** Practice project created to demonstrate Power BI skills.

## Problem
Which pages and content types bring in the most search clicks, and how did click-through rate (CTR) change over 2025?

## Dataset
`seo_performance.csv` has 480 rows of monthly page-level search data for 20 pages: month, page URL, target keyword, content type, device, impressions, clicks and average position.

## Tools
Power BI Desktop (Power Query, DAX measures)

## What I did
1. Loaded the CSV and set correct data types in Power Query
2. Created DAX measures: Total Clicks, Total Impressions, CTR, Avg Position
3. Built a 2-page dashboard: **Overview** and **Content Analysis**
4. Added a Device slicer to filter by Mobile or Desktop
